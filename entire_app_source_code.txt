# Neumorphic Hardware Timer & Stopwatch (Android + Jetpack Glance)

[![Build Android APKs & Release](https://github.com/harrisz123/neumorphic-hardware-timer/actions/workflows/build-apk.yml/badge.svg)](https://github.com/harrisz123/neumorphic-hardware-timer/actions/workflows/build-apk.yml)

An ultra-realistic, 1:1 hardware clone of an industrial precision rotary timer and stopwatch built with **Kotlin**, **Jetpack Compose Canvas**, and **Jetpack Glance 1.1.0** Home Screen Widgets.

---

## Hardware Aesthetic & Visual Specifications
- **Chassis Body:** Warm matte stone/beige (`#DDD9CE`) with soft ambient drop shadows (`#C4C0B5`) and top-left specular highlight (`#EAE6DC`).
- **Recessed Track Well:** Dual-tone carved annular trench (`#CFCBC0`) with inverted inner shadow stroke (`#B5B1A6` to `#E8E4D9`).
- **Main Rotary Platter:** Brushed stone gradient (`#E4E0D5` to `#D2CEC3`) with an illuminated orange pointer (`#FF9500`).
- **Center 3D Knob Cap:** Floating extruded cylinder (`#E2DFD5` top face, `#C2BEB3` 3D side wall) elevated with a dedicated 10dp drop shadow via `BlurMaskFilter(24f, Blur.NORMAL)`.
- **Top Indicators:**
  - Left: Sunken well (`#2B261D`) with specular apex dot (`#9E8C60`) and "Done" indicator.
  - Right: Glowing amber core (`#FF9E1B`), inner border (`#D97200`), and outer radial halo (`0x66FF9E1B`) with "Start" indicator.
- **Bottom Mode Pills:** Recessed bevel pills for Timer and Stopwatch modes (`#F5B800` active fill, `#C4C0B5` inactive).

---

## Audio & Haptics Engine (`TactileFeedbackEngine`)
- **Zero-Asset In-Memory PCM Audio:** Synthesizes an exponentially decaying burst of resonant bandpass-filtered noise (2800Hz, Q=2.4) + an 1800Hz metallic sine transient into a 176-sample ShortArray (4ms at 44.1kHz). Played via low-latency static `AudioTrack` with near-zero latency.
- **Continuous Rotary Math:** Polar angle tracking via `atan2` with continuous wrap-around normalization (`if (delta > 180) delta -= 360; if (delta < -180) delta += 360`) and discrete 6° detent quantization.
- **Hardware Haptics:** Direct API 30+ `VibrationEffect.Composition` primitive clicks with fallbacks.
- **Synthesized Completion Chime:** Dual-tone harmonious bell chime (880Hz A5 + 1760Hz overtone) on timer finish.

---

## Home Screen Widget & Fast-Scrub Overlay
- **Dual-Mode Widget (`Jetpack Glance 1.1.0`):** Renders to a 600x600 offscreen `Bitmap` canvas to circumvent `RemoteViews` gesture conflicts.
- **Interactive Tap Zones:** Overlaid transparent Glance targets for direct Start/Pause toggling and ±1m quick steps.
- **Instant 60fps Scrub Overlay (`QuickDialOverlayActivity`):** Launches a translucent floating dial over the widget so users can smoothly scrub the dial with real-time sound and haptic detents.

package com.neumorphic.hardwaretimer

import android.content.Context
import android.media.AudioAttributes
import android.media.AudioFormat
import android.media.AudioTrack
import android.os.Build
import android.os.VibrationEffect
import android.os.Vibrator
import android.os.VibratorManager
import android.view.HapticFeedbackConstants
import android.view.View
import java.util.Random
import kotlin.math.PI
import kotlin.math.atan2
import kotlin.math.cos
import kotlin.math.exp
import kotlin.math.floor
import kotlin.math.sin

/**
 * Self-contained tactile feedback engine providing:
 * 1. Polar angle tracking and continuous shortest-path angle unwrapping.
 * 2. 6-degree detent quantization (60 ticks / 360 degrees).
 * 3. High-fidelity hardware haptics (API 30+ primitive click compositions with fallbacks).
 * 4. Zero-asset, synthesized in-memory mechanical camera/dial detent click via low-latency static AudioTrack.
 */
class TactileFeedbackEngine(private val context: Context) {

    companion object {
        const val DEGREES_PER_TICK = 6.0f
        const val SAMPLE_RATE = 44100
        const val DURATION_MS = 4
        // 4ms at 44100Hz = 176 samples
        const val NUM_SAMPLES = (SAMPLE_RATE * (DURATION_MS / 1000.0)).toInt()
    }

    private val vibrator: Vibrator? by lazy {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            val vibratorManager = context.getSystemService(Context.VIBRATOR_MANAGER_SERVICE) as? VibratorManager
            vibratorManager?.defaultVibrator
        } else {
            @Suppress("DEPRECATION")
            context.getSystemService(Context.VIBRATOR_SERVICE) as? Vibrator
        }
    }

    private var audioTrack: AudioTrack? = null
    private val pcmBuffer: ShortArray = ShortArray(NUM_SAMPLES)

    // Continuous touch angle state tracking
    private var lastRawAngleDegrees: Float? = null
    private var accumulatedAngleDegrees: Float = 0f
    private var lastTickIndex: Int = 0

    init {
        synthesizeMechanicalClickWaveform()
        initializeStaticAudioTrack()
    }

    /**
     * Synthesizes an exponentially decaying burst of bandpass-filtered white noise + 1800Hz sine transient.
     * Mimics an authentic industrial metal ball-bearing detent drop.
     */
    private fun synthesizeMechanicalClickWaveform() {
        val random = Random(1337L) // Deterministic seed for crisp, identical detent response

        // Resonant bandpass filter configuration (Center = 2800 Hz, Q = 2.4)
        val centerFreq = 2800.0
        val qFactor = 2.4
        val omega = 2.0 * PI * centerFreq / SAMPLE_RATE
        val alpha = sin(omega) / (2.0 * qFactor)

        val b0 = alpha
        val b1 = 0.0
        val b2 = -alpha
        val a0 = 1.0 + alpha
        val a1 = -2.0 * cos(omega)
        val a2 = 1.0 - alpha

        var x1 = 0.0
        var x2 = 0.0
        var y1 = 0.0
        var y2 = 0.0

        for (i in 0 until NUM_SAMPLES) {
            val t = i.toDouble() / SAMPLE_RATE

            // Steep exponential envelope decaying to silence within 4ms
            val decay = exp(-t * 1250.0)

            // 1800 Hz sine wave for the high-frequency metallic impact transient
            val sineTransient = sin(2.0 * PI * 1800.0 * t)

            // Bandpass-filtered noise for the tactile spring friction
            val whiteNoise = (random.nextDouble() * 2.0 - 1.0)
            val filteredNoise = (b0 / a0) * whiteNoise + (b1 / a0) * x1 + (b2 / a0) * x2 - (a1 / a0) * y1 - (a2 / a0) * y2
            x2 = x1
            x1 = whiteNoise
            y2 = y1
            y1 = filteredNoise

            // Mix: 55% metallic transient + 45% textured noise
            val composite = (0.55 * sineTransient + 0.45 * filteredNoise) * decay
            pcmBuffer[i] = (composite * 32767.0).toInt().coerceIn(-32768, 32767).toShort()
        }
    }

    private fun initializeStaticAudioTrack() {
        try {
            val bufferSizeBytes = pcmBuffer.size * 2
            val attributes = AudioAttributes.Builder()
                .setUsage(AudioAttributes.USAGE_ASSISTANCE_SONIFICATION)
                .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
                .build()

            val format = AudioFormat.Builder()
                .setEncoding(AudioFormat.ENCODING_PCM_16BIT)
                .setSampleRate(SAMPLE_RATE)
                .setChannelMask(AudioFormat.CHANNEL_OUT_MONO)
                .build()

            val track = AudioTrack.Builder()
                .setAudioAttributes(attributes)
                .setAudioFormat(format)
                .setBufferSizeInBytes(bufferSizeBytes)
                .setTransferMode(AudioTrack.MODE_STATIC)
                .build()

            track.write(pcmBuffer, 0, pcmBuffer.size)
            audioTrack = track
        } catch (e: Exception) {
            audioTrack = null
        }
    }

    /**
     * Plays the in-memory synthesized audio detent click with near-zero latency.
     */
    fun playTickAudio() {
        try {
            audioTrack?.let { track ->
                if (track.playState == AudioTrack.PLAYSTATE_PLAYING) {
                    track.stop()
                }
                track.reloadStaticData()
                track.play()
            }
        } catch (e: Exception) {
            // AudioTrack state recovery
        }
    }

    /**
     * Dispatches hardware haptic feedback according to platform version and hardware support.
     */
    fun playTickHaptic(fallbackView: View? = null) {
        val vib = vibrator
        if (vib != null && vib.hasVibrator()) {
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
                if (vib.areAllPrimitivesSupported(VibrationEffect.Composition.PRIMITIVE_CLICK)) {
                    val composition = VibrationEffect.startComposition()
                        .addPrimitive(VibrationEffect.Composition.PRIMITIVE_CLICK, 0.7f)
                        .compose()
                    vib.vibrate(composition)
                    return
                } else {
                    vib.vibrate(VibrationEffect.createPredefined(VibrationEffect.EFFECT_TICK))
                    return
                }
            } else if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
                vib.vibrate(VibrationEffect.createOneShot(8L, 90))
                return
            } else {
                @Suppress("DEPRECATION")
                vib.vibrate(8L)
                return
            }
        }

        fallbackView?.performHapticFeedback(
            HapticFeedbackConstants.CLOCK_TICK,
            HapticFeedbackConstants.FLAG_IGNORE_GLOBAL_SETTING
        )
    }

    /**
     * Triggers both physical haptics and synthesized mechanical audio simultaneously.
     */
    fun triggerDetentFeedback(fallbackView: View? = null) {
        playTickAudio()
        playTickHaptic(fallbackView)
    }

    /**
     * Computes the clock angle in degrees (0..360, where 0 deg is 12 o'clock, 90 deg is 3 o'clock).
     */
    fun calculateClockAngle(touchX: Float, touchY: Float, centerX: Float, centerY: Float): Float {
        val dx = touchX - centerX
        val dy = touchY - centerY
        var deg = Math.toDegrees(atan2(dy.toDouble(), dx.toDouble())).toFloat() + 90.0f
        if (deg < 0f) deg += 360.0f
        return deg % 360.0f
    }

    fun onTouchDown(touchX: Float, touchY: Float, centerX: Float, centerY: Float, currentDialAngle: Float) {
        lastRawAngleDegrees = calculateClockAngle(touchX, touchY, centerX, centerY)
        accumulatedAngleDegrees = currentDialAngle
        lastTickIndex = floor(accumulatedAngleDegrees / DEGREES_PER_TICK).toInt()
    }

    fun onTouchUp() {
        lastRawAngleDegrees = null
    }

    /**
     * Processes circular rotary drag coordinates.
     * GUARDRAIL FIX: Normalizes wrap-around jump across 359° to 0°:
     * var delta = newAngle - lastAngle; if (delta > 180) delta -= 360; if (delta < -180) delta += 360
     * Ensures moving from 359° to 0° adds +1 minute instead of subtracting 60 minutes.
     *
     * @return Pair(newDialAngleDegrees, tickDeltaCount)
     */
    fun onRotaryDrag(
        touchX: Float,
        touchY: Float,
        centerX: Float,
        centerY: Float,
        fallbackView: View? = null
    ): Pair<Float, Int> {
        val newAngle = calculateClockAngle(touchX, touchY, centerX, centerY)
        val lastAngle = lastRawAngleDegrees ?: newAngle
        lastRawAngleDegrees = newAngle

        // Exact Guardrail Specification: Normalize angular wrap-around
        var delta = newAngle - lastAngle
        if (delta > 180) delta -= 360
        if (delta < -180) delta += 360

        accumulatedAngleDegrees += delta
        val newTickIndex = floor(accumulatedAngleDegrees / DEGREES_PER_TICK).toInt()
        val tickDiff = newTickIndex - lastTickIndex

        if (tickDiff != 0) {
            triggerDetentFeedback(fallbackView)
            lastTickIndex = newTickIndex
        }

        val normalizedAngle = ((accumulatedAngleDegrees % 360f) + 360f) % 360f
        return Pair(normalizedAngle, tickDiff)
    }

    fun release() {
        try {
            audioTrack?.let {
                if (it.playState == AudioTrack.PLAYSTATE_PLAYING) {
                    it.stop()
                }
                it.release()
            }
            audioTrack = null
        } catch (e: Exception) {
            // Ignore on teardown
        }
    }
}

enum class DeviceMode {
    TIMER,
    STOPWATCH
}

@Composable
fun NeumorphicDialCanvas(
    mode: DeviceMode,
    displayText: String,
    dialAngleDegrees: Float,
    isRunning: Boolean,
    isDone: Boolean,
    tactileEngine: TactileFeedbackEngine,
    onDialAngleChanged: (Float, Int) -> Unit,
    onKnobTapped: () -> Unit,
    onKnobLongPressed: () -> Unit,
    onStartAreaTapped: () -> Unit,
    onModeChanged: (DeviceMode) -> Unit,
    modifier: Modifier = Modifier
) {
    val textMeasurer = rememberTextMeasurer()
    val localView = LocalView.current

    var isKnobPressed by remember { mutableStateOf(false) }

    val knobShadowOffsetDp by animateFloatAsState(
        targetValue = if (isKnobPressed) 4f else 10f,
        animationSpec = tween(durationMillis = 100),
        label = "knobDepression"
    )

    Box(
        modifier = modifier
            .size(320.dp)
            .pointerInput(mode, isRunning) {
                val chassisWidthPx = 320.dp.toPx()
                val chassisHeightPx = 320.dp.toPx()
                val cx = chassisWidthPx / 2f
                val cy = chassisHeightPx / 2f
                val knobRadiusPx = 52.dp.toPx()

                detectTapGestures(
                    onPress = { offset ->
                        val dx = offset.x - cx
                        val dy = offset.y - cy
                        if (sqrt(dx * dx + dy * dy) <= knobRadiusPx) {
                            isKnobPressed = true
                            tryAwaitRelease()
                            isKnobPressed = false
                        }
                    },
                    onTap = { offset ->
                        val dx = offset.x - cx
                        val dy = offset.y - cy
                        val distFromCenter = sqrt(dx * dx + dy * dy)

                        // 1. Center Knob Tap
                        if (distFromCenter <= knobRadiusPx) {
                            tactileEngine.triggerDetentFeedback(localView)
                            onKnobTapped()
                            return@detectTapGestures
                        }

                        // 2. Top-Right "Start" Indicator Area Tap
                        val startAreaCenter = Offset(chassisWidthPx - 44.dp.toPx(), 40.dp.toPx())
                        if ((offset - startAreaCenter).getDistance() < 36.dp.toPx()) {
                            tactileEngine.triggerDetentFeedback(localView)
                            onStartAreaTapped()
                            return@detectTapGestures
                        }

                        // 3. Bottom Pill Buttons
                        val bottomY = chassisHeightPx - 32.dp.toPx()
                        val pillWidthPx = 28.dp.toPx()
                        val pillHeightPx = 10.dp.toPx()

                        val leftPillRect = Rect(
                            left = 48.dp.toPx() - pillWidthPx,
                            top = bottomY - pillHeightPx * 2,
                            right = 48.dp.toPx() + pillWidthPx,
                            bottom = bottomY + pillHeightPx * 2
                        )
                        if (leftPillRect.contains(offset)) {
                            tactileEngine.triggerDetentFeedback(localView)
                            onModeChanged(DeviceMode.TIMER)
                            return@detectTapGestures
                        }

                        val rightPillRect = Rect(
                            left = (chassisWidthPx - 48.dp.toPx()) - pillWidthPx,
                            top = bottomY - pillHeightPx * 2,
                            right = (chassisWidthPx - 48.dp.toPx()) + pillWidthPx,
                            bottom = bottomY + pillHeightPx * 2
                        )
                        if (rightPillRect.contains(offset)) {
                            tactileEngine.triggerDetentFeedback(localView)
                            onModeChanged(DeviceMode.STOPWATCH)
                            return@detectTapGestures
                        }
                    },
                    onLongPress = { offset ->
                        val dx = offset.x - cx
                        val dy = offset.y - cy
                        if (sqrt(dx * dx + dy * dy) <= knobRadiusPx) {
                            tactileEngine.triggerDetentFeedback(localView)
                            onKnobLongPressed()
                        }
                    }
                )
            }
            .pointerInput(mode, isRunning) {
                val cx = 320.dp.toPx() / 2f
                val cy = 320.dp.toPx() / 2f
                val innerPlatterPx = 52.dp.toPx()
                val outerPlatterPx = 114.dp.toPx()

                detectDragGestures(
                    onDragStart = { offset ->
                        val dx = offset.x - cx
                        val dy = offset.y - cy
                        val dist = sqrt(dx * dx + dy * dy)
                        if (dist in innerPlatterPx..outerPlatterPx) {
                            tactileEngine.onTouchDown(offset.x, offset.y, cx, cy, dialAngleDegrees)
                        }
                    },
                    onDragEnd = { tactileEngine.onTouchUp() },
                    onDragCancel = { tactileEngine.onTouchUp() },
                    onDrag = { change, _ ->
                        val pos = change.position
                        val dx = pos.x - cx
                        val dy = pos.y - cy
                        val dist = sqrt(dx * dx + dy * dy)

                        if (dist in (innerPlatterPx * 0.8f)..(outerPlatterPx * 1.25f)) {
                            change.consume()
                            val (newAngle, tickDiff) = tactileEngine.onRotaryDrag(
                                pos.x, pos.y, cx, cy, localView
                            )
                            if (tickDiff != 0) {
                                onDialAngleChanged(newAngle, tickDiff)
                            }
                        }
                    }
                )
            }
    ) {
        androidx.compose.foundation.Canvas(modifier = Modifier.fillMaxSize()) {
            val chassisSize = size.width
            val cx = size.width / 2f
            val cy = size.height / 2f

            // 1. NEUMORPHIC CHASSIS (Square 320dp, CornerRadius 48dp)
            drawChassisNeumorphicHousing(chassisSize, 48.dp.toPx())

            // 2. TOP INDICATORS (Done on Left, Start on Right)
            drawTopIndicators(chassisSize, isRunning, isDone, textMeasurer)

            // 3. 12 RADIAL TICK MARKS (Radius 122dp to 128dp every 30 deg)
            drawRadialTicks(cx, cy, 122.dp.toPx(), 128.dp.toPx())

            // 4. RECESSED TRACK WELL (Outer Ring, Radius 112dp with inverted inner shadow bevel)
            drawRecessedTrackWell(cx, cy, 112.dp.toPx())

            // 5. MAIN ROTARY PLATTER (Middle Ring, Radius 104dp)
            drawRotaryPlatter(cx, cy, 104.dp.toPx(), dialAngleDegrees)

            // 6. CENTER KNOB CAP (Stationary / Pressable, Radius 52dp with dedicated BlurMaskFilter shadow)
            drawCenterKnob(cx, cy, 52.dp.toPx(), knobShadowOffsetDp.dp.toPx(), displayText, textMeasurer)

            // 7. BOTTOM MODE PILL BUTTONS (Timer & Stopwatch)
            drawBottomPills(chassisSize, chassisSize, mode)
        }
    }
}

private fun DrawScope.drawChassisNeumorphicHousing(chassisSize: Float, cornerRadius: Float) {
    val cr = CornerRadius(cornerRadius, cornerRadius)

    drawIntoCanvas { canvas ->
        val native = canvas.nativeCanvas

        val shadowPaint = AndroidPaint().apply {
            color = HardwarePalette.ChassisDropShadow.toArgb()
            isAntiAlias = true
            maskFilter = BlurMaskFilter(20f, BlurMaskFilter.Blur.NORMAL)
        }
        native.drawRoundRect(
            10f, 12f,
            chassisSize + 10f, chassisSize + 14f,
            cornerRadius, cornerRadius,
            shadowPaint
        )

        val highlightPaint = AndroidPaint().apply {
            color = HardwarePalette.ChassisRimHighlight.toArgb()
            isAntiAlias = true
            maskFilter = BlurMaskFilter(16f, BlurMaskFilter.Blur.NORMAL)
        }
        native.drawRoundRect(
            -8f, -8f,
            chassisSize - 8f, chassisSize - 8f,
            cornerRadius, cornerRadius,
            highlightPaint
        )
    }

    drawRoundRect(
        color = HardwarePalette.ChassisBody,
        topLeft = Offset(0f, 0f),
        size = Size(chassisSize, chassisSize),
        cornerRadius = cr
    )

    drawRoundRect(
        brush = Brush.linearGradient(
            colors = listOf(
                HardwarePalette.ChassisRimHighlight,
                Color.Transparent,
                HardwarePalette.ChassisDropShadow.copy(alpha = 0.35f)
            ),
            start = Offset(0f, 0f),
            end = Offset(chassisSize, chassisSize)
        ),
        topLeft = Offset(0.5f, 0.5f),
        size = Size(chassisSize - 1f, chassisSize - 1f),
        cornerRadius = cr,
        style = Stroke(width = 1.5f)
    )
}

private fun DrawScope.drawTopIndicators(
    chassisWidth: Float,
    isRunning: Boolean,
    isDone: Boolean,
    textMeasurer: TextMeasurer
) {
    val leftCenterX = 44.dp.toPx()
    val topY = 40.dp.toPx()
    val rightCenterX = chassisWidth - 44.dp.toPx()
    val doneLedRadius = 6.dp.toPx()

    // --- TOP-LEFT: "Done" + Recessed Dark LED ---
    drawCircle(
        color = HardwarePalette.LedDarkWell,
        radius = doneLedRadius,
        center = Offset(leftCenterX, topY)
    )
    drawCircle(
        brush = Brush.radialGradient(
            colors = listOf(Color.Transparent, Color.Black.copy(alpha = 0.6f)),
            center = Offset(leftCenterX, topY),
            radius = doneLedRadius
        ),
        radius = doneLedRadius,
        center = Offset(leftCenterX, topY)
    )
    val centerDotColor = if (isDone) HardwarePalette.PillActiveBottomRim else HardwarePalette.LedDarkDot
    drawCircle(
        color = centerDotColor,
        radius = 1.8.dp.toPx(),
        center = Offset(leftCenterX, topY)
    )
    if (isDone) {
        drawCircle(
            color = HardwarePalette.DialPointerOrange.copy(alpha = 0.45f),
            radius = 10.dp.toPx(),
            center = Offset(leftCenterX, topY)
        )
    }

    val doneTextResult = textMeasurer.measure(
        text = "Done",
        style = TextStyle(
            color = HardwarePalette.SecondaryLabels,
            fontSize = 13.sp,
            fontWeight = FontWeight.Medium,
            fontFamily = FontFamily.SansSerif
        )
    )
    drawText(
        textLayoutResult = doneTextResult,
        topLeft = Offset(leftCenterX + 12.dp.toPx(), topY - (doneTextResult.size.height / 2f))
    )

    // --- TOP-RIGHT: "Start" + Glowing Amber LED ---
    val startTextResult = textMeasurer.measure(
        text = "Start",
        style = TextStyle(
            color = HardwarePalette.SecondaryLabels,
            fontSize = 13.sp,
            fontWeight = FontWeight.Medium,
            fontFamily = FontFamily.SansSerif
        )
    )
    drawText(
        textLayoutResult = startTextResult,
        topLeft = Offset(rightCenterX - 14.dp.toPx() - startTextResult.size.width, topY - (startTextResult.size.height / 2f))
    )

    val startLedRadius = 6.dp.toPx()
    if (isRunning) {
        drawCircle(
            color = HardwarePalette.LedAmberGlow,
            radius = 12.dp.toPx(),
            center = Offset(rightCenterX, topY)
        )
        drawCircle(
            brush = Brush.radialGradient(
                colors = listOf(
                    HardwarePalette.LedAmberCore,
                    HardwarePalette.LedAmberGlow,
                    Color.Transparent
                ),
                center = Offset(rightCenterX, topY),
                radius = 10.dp.toPx()
            ),
            radius = 10.dp.toPx(),
            center = Offset(rightCenterX, topY)
        )
        drawCircle(
            color = HardwarePalette.LedAmberBorder,
            radius = startLedRadius,
            center = Offset(rightCenterX, topY)
        )
        drawCircle(
            color = HardwarePalette.LedAmberCore,
            radius = 4.2.dp.toPx(),
            center = Offset(rightCenterX, topY)
        )
        drawCircle(
            color = HardwarePalette.LedAmberHighlight,
            radius = 1.6.dp.toPx(),
            center = Offset(rightCenterX - 1.2f, topY - 1.2f)
        )
    } else {
        drawCircle(
            color = HardwarePalette.LedAmberBorder.copy(alpha = 0.35f),
            radius = startLedRadius,
            center = Offset(rightCenterX, topY)
        )
        drawCircle(
            color = HardwarePalette.LedAmberCore.copy(alpha = 0.5f),
            radius = 3.5.dp.toPx(),
            center = Offset(rightCenterX, topY)
        )
    }
}

private fun DrawScope.drawRadialTicks(cx: Float, cy: Float, innerRadius: Float, outerRadius: Float) {
    for (i in 0 until 12) {
        val angleDeg = i * 30f
        val angleRad = (angleDeg - 90f) * (PI / 180.0)

        val cosA = cos(angleRad).toFloat()
        val sinA = sin(angleRad).toFloat()

        val start = Offset(cx + innerRadius * cosA, cy + innerRadius * sinA)
        val end = Offset(cx + outerRadius * cosA, cy + outerRadius * sinA)

        val isCardinal12 = (i == 0)
        val tickColor = if (isCardinal12) HardwarePalette.DialPointerOrange else HardwarePalette.MinorRadialTick
        val strokeWidth = if (isCardinal12) 2.5.dp.toPx() else 1.5.dp.toPx()

        drawLine(
            color = tickColor,
            start = start,
            end = end,
            strokeWidth = strokeWidth,
            cap = StrokeCap.Round
        )
    }
}

/**
 * 4. Recessed Track Well:
 * Radius: 112dp from center.
 * Base color: #CFCBC0 with inner gradient.
 * GUARDRAIL FIX: Uses a Brush.linearGradient from #B5B1A6 (top-left) to #E8E4D9 (bottom-right)
 * on the outer ring stroke to create an authentic inverted inner shadow.
 */
private fun DrawScope.drawRecessedTrackWell(cx: Float, cy: Float, radius: Float) {
    // Trench base plate
    drawCircle(
        color = HardwarePalette.RecessedTrackWell,
        radius = radius,
        center = Offset(cx, cy)
    )

    // Inner top diffuse shadow
    drawCircle(
        brush = Brush.linearGradient(
            colors = listOf(
                HardwarePalette.RecessedInnerShadow.copy(alpha = 0.95f),
                HardwarePalette.RecessedTrackWell,
                HardwarePalette.ChassisRimHighlight.copy(alpha = 0.5f)
            ),
            start = Offset(cx, cy - radius),
            end = Offset(cx, cy + radius)
        ),
        radius = radius,
        center = Offset(cx, cy)
    )

    // Guardrail specification: Inverted inner shadow bevel stroke
    drawCircle(
        brush = Brush.linearGradient(
            colors = listOf(
                HardwarePalette.RecessedBevelTopLeft,     // #B5B1A6 (top-left)
                HardwarePalette.RecessedBevelBottomRight  // #E8E4D9 (bottom-right)
            ),
            start = Offset(cx - radius, cy - radius),
            end = Offset(cx + radius, cy + radius)
        ),
        radius = radius,
        center = Offset(cx, cy),
        style = Stroke(width = 2.dp.toPx())
    )
}

private fun DrawScope.drawRotaryPlatter(cx: Float, cy: Float, radius: Float, dialAngleDegrees: Float) {
    drawCircle(
        color = Color(0x33000000),
        radius = radius + 1f,
        center = Offset(cx + 1.5f, cy + 3f)
    )

    drawCircle(
        brush = Brush.linearGradient(
            colors = listOf(
                HardwarePalette.PlatterTopGradient,
                HardwarePalette.PlatterBottomGradient
            ),
            start = Offset(cx, cy - radius),
            end = Offset(cx, cy + radius)
        ),
        radius = radius,
        center = Offset(cx, cy)
    )

    drawCircle(
        brush = Brush.linearGradient(
            colors = listOf(
                Color.White.copy(alpha = 0.6f),
                Color.Transparent,
                Color.Black.copy(alpha = 0.25f)
            ),
            start = Offset(cx - radius, cy - radius),
            end = Offset(cx + radius, cy + radius)
        ),
        radius = radius,
        center = Offset(cx, cy),
        style = Stroke(width = 1.5f)
    )

    val pointerInnerRadius = 72.dp.toPx()
    val pointerOuterRadius = 98.dp.toPx()
    val pointerAngleRad = (dialAngleDegrees - 90f) * (PI / 180.0)

    val pCos = cos(pointerAngleRad).toFloat()
    val pSin = sin(pointerAngleRad).toFloat()

    val pStart = Offset(cx + pointerInnerRadius * pCos, cy + pointerInnerRadius * pSin)
    val pEnd = Offset(cx + pointerOuterRadius * pCos, cy + pointerOuterRadius * pSin)

    drawLine(
        color = HardwarePalette.DialPointerOrange.copy(alpha = 0.35f),
        start = pStart,
        end = pEnd,
        strokeWidth = 5.dp.toPx(),
        cap = StrokeCap.Round
    )

    drawLine(
        color = HardwarePalette.DialPointerOrange,
        start = pStart,
        end = pEnd,
        strokeWidth = 3.dp.toPx(),
        cap = StrokeCap.Round
    )
}

/**
 * 6. Center Stationary / Pressable Knob Cap:
 * Radius: 52dp.
 * GUARDRAIL FIX: Draws a dedicated drawCircle shadow layer shifted y + 10.dp with a BlurMaskFilter(24f, Blur.NORMAL)
 * inside drawIntoCanvas before drawing the knob cap.
 */
private fun DrawScope.drawCenterKnob(
    cx: Float,
    cy: Float,
    radius: Float,
    shadowOffsetPx: Float,
    displayText: String,
    textMeasurer: TextMeasurer
) {
    // 1. Guardrail specification: Dedicated drawCircle shadow layer shifted y + 10.dp with BlurMaskFilter(24f, Blur.NORMAL)
    drawIntoCanvas { canvas ->
        val native = canvas.nativeCanvas

        val knobShadowPaint = AndroidPaint().apply {
            color = HardwarePalette.CenterKnobShadow.toArgb()
            isAntiAlias = true
            maskFilter = BlurMaskFilter(24f, BlurMaskFilter.Blur.NORMAL)
        }
        native.drawCircle(
            cx,
            cy + shadowOffsetPx, // Animates to 10.dp resting offset
            radius + 1f,
            knobShadowPaint
        )
    }

    // 2. 3D Extruded cylinder side wall
    val extrusionHeight = shadowOffsetPx * 0.7f
    drawCircle(
        color = HardwarePalette.CenterKnobSideWall,
        radius = radius,
        center = Offset(cx, cy + extrusionHeight)
    )

    drawCircle(
        brush = Brush.linearGradient(
            colors = listOf(
                Color.Transparent,
                HardwarePalette.CenterKnobShadow.copy(alpha = 0.45f)
            ),
            start = Offset(cx, cy),
            end = Offset(cx, cy + extrusionHeight + radius)
        ),
        radius = radius,
        center = Offset(cx, cy + extrusionHeight)
    )

    // 3. Top face of knob
    val knobTopCenter = Offset(cx, cy)
    drawCircle(
        color = HardwarePalette.CenterKnobTopFace,
        radius = radius,
        center = knobTopCenter
    )

    drawCircle(
        brush = Brush.linearGradient(
            colors = listOf(
                Color.White.copy(alpha = 0.5f),
                HardwarePalette.CenterKnobTopFace,
                HardwarePalette.CenterKnobSideWall.copy(alpha = 0.4f)
            ),
            start = Offset(cx, cy - radius),
            end = Offset(cx, cy + radius)
        ),
        radius = radius,
        center = knobTopCenter
    )

    drawCircle(
        color = Color.White.copy(alpha = 0.35f),
        radius = radius - 0.5f,
        center = knobTopCenter,
        style = Stroke(width = 1f)
    )

    val fontSize = if (displayText.length > 4) 26.sp else 32.sp
    val textResult = textMeasurer.measure(
        text = displayText,
        style = TextStyle(
            color = HardwarePalette.CenterTypography,
            fontSize = fontSize,
            fontWeight = FontWeight.SemiBold,
            fontFamily = FontFamily.SansSerif
        )
    )
    val textTopLeft = Offset(
        cx - (textResult.size.width / 2f),
        cy - (textResult.size.height / 2f)
    )
    drawText(
        textLayoutResult = textResult,
        topLeft = textTopLeft
    )
}

private fun DrawScope.drawBottomPills(
    chassisWidth: Float,
    chassisHeight: Float,
    activeMode: DeviceMode
) {
    val pillWidth = 28.dp.toPx()
    val pillHeight = 6.dp.toPx()
    val pillCorner = CornerRadius(4.dp.toPx(), 4.dp.toPx())
    val pillY = chassisHeight - 32.dp.toPx()

    val leftPillX = 48.dp.toPx() - (pillWidth / 2f)
    drawSinglePill(
        topLeft = Offset(leftPillX, pillY),
        width = pillWidth,
        height = pillHeight,
        cornerRadius = pillCorner,
        isActive = (activeMode == DeviceMode.TIMER)
    )

    val rightPillX = (chassisWidth - 48.dp.toPx()) - (pillWidth / 2f)
    drawSinglePill(
        topLeft = Offset(rightPillX, pillY),
        width = pillWidth,
        height = pillHeight,
        cornerRadius = pillCorner,
        isActive = (activeMode == DeviceMode.STOPWATCH)
    )
}

private fun DrawScope.drawSinglePill(
    topLeft: Offset,
    width: Float,
    height: Float,
    cornerRadius: CornerRadius,
    isActive: Boolean
) {
    val pillSize = Size(width, height)

    if (isActive) {
        drawRoundRect(
            color = HardwarePalette.PillActiveFill,
            topLeft = topLeft,
            size = pillSize,
            cornerRadius = cornerRadius
        )

        drawRoundRect(
            brush = Brush.verticalGradient(
                colors = listOf(HardwarePalette.PillActiveTopBevel, Color.Transparent),
                startY = topLeft.y,
                endY = topLeft.y + height
            ),
            topLeft = topLeft,
            size = pillSize,
            cornerRadius = cornerRadius
        )

        drawRoundRect(
            brush = Brush.verticalGradient(
                colors = listOf(Color.Transparent, HardwarePalette.PillActiveBottomRim),
                startY = topLeft.y,
                endY = topLeft.y + height
            ),
            topLeft = topLeft,
            size = pillSize,
            cornerRadius = cornerRadius,
            style = Stroke(width = 1f)
        )
    } else {
        drawRoundRect(
            color = HardwarePalette.PillInactive,
            topLeft = topLeft,
            size = pillSize,
            cornerRadius = cornerRadius
        )

        drawRoundRect(
            color = HardwarePalette.RecessedInnerShadow.copy(alpha = 0.5f),
            topLeft = topLeft,
            size = pillSize,
            cornerRadius = cornerRadius,
            style = Stroke(width = 1f)
        )
    }
}

/**
 * Precision hardware state model representing the exact state of the industrial dial.
 */
data class HardwareState(
    val mode: DeviceMode = DeviceMode.TIMER,
    val timerTotalSeconds: Int = 30 * 60, // Default 30m
    val timerRemainingSeconds: Int = 30 * 60,
    val stopwatchElapsedMillis: Long = 0L,
    val isRunning: Boolean = false,
    val isDone: Boolean = false,
    val dialAngleDegrees: Float = 0f
) {
    val displayText: String
        get() = when (mode) {
            DeviceMode.TIMER -> {
                if (!isRunning && !isDone && timerRemainingSeconds % 60 == 0 && timerRemainingSeconds >= 60) {
                    "${timerRemainingSeconds / 60}m"
                } else {
                    val m = timerRemainingSeconds / 60
                    val s = timerRemainingSeconds % 60
                    String.format("%02d:%02d", m, s)
                }
            }
            DeviceMode.STOPWATCH -> {
                val totalSeconds = (stopwatchElapsedMillis / 1000).toInt()
                val m = totalSeconds / 60
                val s = totalSeconds % 60
                String.format("%02d:%02d", m, s)
            }
        }
}

/**
 * Singleton repository holding reactive state shared across App, Service, and Widget.
 */
object HardwareStateRepository {
    private const val PREFS_NAME = "neumorphic_timer_prefs"
    private const val KEY_MODE = "device_mode"
    private const val KEY_TOTAL_SEC = "total_sec"
    private const val KEY_REM_SEC = "rem_sec"
    private const val KEY_STOPWATCH_MS = "stopwatch_ms"
    private const val KEY_IS_RUNNING = "is_running"
    private const val KEY_IS_DONE = "is_done"
    private const val KEY_DIAL_ANGLE = "dial_angle"

    private val _state = MutableStateFlow(HardwareState())
    val state: StateFlow<HardwareState> = _state.asStateFlow()

    private val scope = CoroutineScope(Dispatchers.Main + SupervisorJob())

    fun init(context: Context) {
        val prefs = context.getSharedPreferences(PREFS_NAME, Context.MODE_PRIVATE)
        val modeStr = prefs.getString(KEY_MODE, DeviceMode.TIMER.name) ?: DeviceMode.TIMER.name
        val mode = try { DeviceMode.valueOf(modeStr) } catch (e: Exception) { DeviceMode.TIMER }
        val totalSec = prefs.getInt(KEY_TOTAL_SEC, 30 * 60)
        val remSec = prefs.getInt(KEY_REM_SEC, 30 * 60)
        val swMs = prefs.getLong(KEY_STOPWATCH_MS, 0L)
        val running = prefs.getBoolean(KEY_IS_RUNNING, false)
        val done = prefs.getBoolean(KEY_IS_DONE, false)
        val angle = prefs.getFloat(KEY_DIAL_ANGLE, 0f)

        _state.value = HardwareState(
            mode = mode,
            timerTotalSeconds = totalSec,
            timerRemainingSeconds = remSec,
            stopwatchElapsedMillis = swMs,
            isRunning = running,
            isDone = done,
            dialAngleDegrees = angle
        )
    }

    fun updateState(context: Context, transform: (HardwareState) -> HardwareState) {
        val newState = transform(_state.value)
        _state.value = newState
        persistState(context, newState)
        notifyWidgetUpdate(context)
    }

    private fun persistState(context: Context, state: HardwareState) {
        val prefs = context.getSharedPreferences(PREFS_NAME, Context.MODE_PRIVATE)
        prefs.edit()
            .putString(KEY_MODE, state.mode.name)
            .putInt(KEY_TOTAL_SEC, state.timerTotalSeconds)
            .putInt(KEY_REM_SEC, state.timerRemainingSeconds)
            .putLong(KEY_STOPWATCH_MS, state.stopwatchElapsedMillis)
            .putBoolean(KEY_IS_RUNNING, state.isRunning)
            .putBoolean(KEY_IS_DONE, state.isDone)
            .putFloat(KEY_DIAL_ANGLE, state.dialAngleDegrees)
            .apply()
    }

    private fun notifyWidgetUpdate(context: Context) {
        scope.launch {
            try {
                TimerAppWidget().updateAll(context)
            } catch (e: Exception) {
                // Ignore during early initialization
            }
        }
    }
}

/**
 * Production Foreground Service providing:
 * 1. Monotonic zero-drift timing via SystemClock.elapsedRealtime().
 * 2. In-memory synthesized dual-tone mechanical chime on timer completion (zero external assets).
 * 3. Haptic alarm pulse sequence on completion.
 * 4. Ongoing system status notification with direct interactive actions.
 */
class TimerForegroundService : Service() {

    companion object {
        const val CHANNEL_ID = "neumorphic_timer_channel"
        const val NOTIFICATION_ID = 1001

        const val ACTION_START = "ACTION_START"
        const val ACTION_PAUSE = "ACTION_PAUSE"
        const val ACTION_TOGGLE = "ACTION_TOGGLE"
        const val ACTION_RESET = "ACTION_RESET"
        const val ACTION_ADJUST_TIMER = "ACTION_ADJUST_TIMER"
        const val EXTRA_DELTA_SECONDS = "EXTRA_DELTA_SECONDS"

        fun startService(context: Context, action: String) {
            val intent = Intent(context, TimerForegroundService::class.java).apply {
                this.action = action
            }
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
                context.startForegroundService(intent)
            } else {
                context.startService(intent)
            }
        }

        fun adjustTimer(context: Context, deltaSeconds: Int) {
            val intent = Intent(context, TimerForegroundService::class.java).apply {
                action = ACTION_ADJUST_TIMER
                putExtra(EXTRA_DELTA_SECONDS, deltaSeconds)
            }
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
                context.startForegroundService(intent)
            } else {
                context.startService(intent)
            }
        }
    }

    private val handler = Handler(Looper.getMainLooper())
    private var baseRealtimeMs: Long = 0L
    private var initialOffsetMs: Long = 0L

    private val vibrator: Vibrator? by lazy {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            val vm = getSystemService(Context.VIBRATOR_MANAGER_SERVICE) as? VibratorManager
            vm?.defaultVibrator
        } else {
            @Suppress("DEPRECATION")
            getSystemService(Context.VIBRATOR_SERVICE) as? Vibrator
        }
    }

    private val tickerRunnable = object : Runnable {
        override fun run() {
            val curState = HardwareStateRepository.state.value
            if (!curState.isRunning) return

            val now = SystemClock.elapsedRealtime()
            val elapsedSinceStart = (now - baseRealtimeMs) + initialOffsetMs

            when (curState.mode) {
                DeviceMode.TIMER -> {
                    val totalMs = curState.timerTotalSeconds * 1000L
                    val remainingMs = (totalMs - elapsedSinceStart).coerceAtLeast(0L)
                    val remainingSeconds = ((remainingMs + 999L) / 1000L).toInt()

                    if (remainingMs <= 0L) {
                        HardwareStateRepository.updateState(applicationContext) {
                            it.copy(
                                timerRemainingSeconds = 0,
                                isRunning = false,
                                isDone = true,
                                dialAngleDegrees = 0f
                            )
                        }
                        triggerCompletionAlarm()
                        updateNotification("Done", "00:00 - Timer Finished")
                        stopForeground(STOP_FOREGROUND_DETACH)
                        return
                    } else {
                        val fractionLeft = remainingMs.toFloat() / totalMs.toFloat().coerceAtLeast(1f)
                        val angle = fractionLeft * 360f

                        HardwareStateRepository.updateState(applicationContext) {
                            it.copy(
                                timerRemainingSeconds = remainingSeconds,
                                dialAngleDegrees = angle
                            )
                        }
                        updateNotification("Timer Running", curState.displayText)
                    }
                }
                DeviceMode.STOPWATCH -> {
                    val dialAngle = ((elapsedSinceStart % 60000L) / 60000f) * 360f
                    HardwareStateRepository.updateState(applicationContext) {
                        it.copy(
                            stopwatchElapsedMillis = elapsedSinceStart,
                            dialAngleDegrees = dialAngle
                        )
                    }
                    updateNotification("Stopwatch Running", curState.displayText)
                }
            }

            handler.postDelayed(this, 50L) // 20fps precision ticker
        }
    }

    override fun onCreate() {
        super.onCreate()
        HardwareStateRepository.init(applicationContext)
        createNotificationChannel()
    }

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        val action = intent?.action ?: ACTION_START
        when (action) {
            ACTION_START -> startRunning()
            ACTION_PAUSE -> pauseRunning()
            ACTION_TOGGLE -> toggleRunning()
            ACTION_RESET -> resetCurrentMode()
            ACTION_ADJUST_TIMER -> {
                val delta = intent?.getIntExtra(EXTRA_DELTA_SECONDS, 60) ?: 60
                adjustTimerBySeconds(delta)
            }
        }
        return START_STICKY
    }

    private fun startRunning() {
        val cur = HardwareStateRepository.state.value
        baseRealtimeMs = SystemClock.elapsedRealtime()

        if (cur.mode == DeviceMode.TIMER) {
            val startingRemaining = if (cur.timerRemainingSeconds <= 0 || cur.isDone) {
                cur.timerTotalSeconds
            } else {
                cur.timerRemainingSeconds
            }
            initialOffsetMs = (cur.timerTotalSeconds - startingRemaining) * 1000L
            HardwareStateRepository.updateState(applicationContext) {
                it.copy(
                    timerRemainingSeconds = startingRemaining,
                    isRunning = true,
                    isDone = false
                )
            }
        } else {
            initialOffsetMs = cur.stopwatchElapsedMillis
            HardwareStateRepository.updateState(applicationContext) {
                it.copy(isRunning = true)
            }
        }

        startForeground(NOTIFICATION_ID, buildNotification("Hardware Dial Active", HardwareStateRepository.state.value.displayText))
        handler.removeCallbacks(tickerRunnable)
        handler.post(tickerRunnable)
    }

    private fun pauseRunning() {
        handler.removeCallbacks(tickerRunnable)
        HardwareStateRepository.updateState(applicationContext) {
            it.copy(isRunning = false)
        }
        val cur = HardwareStateRepository.state.value
        updateNotification("Paused", cur.displayText)
        stopForeground(STOP_FOREGROUND_DETACH)
    }

    private fun toggleRunning() {
        if (HardwareStateRepository.state.value.isRunning) {
            pauseRunning()
        } else {
            startRunning()
        }
    }

    private fun resetCurrentMode() {
        handler.removeCallbacks(tickerRunnable)
        initialOffsetMs = 0L
        baseRealtimeMs = SystemClock.elapsedRealtime()

        HardwareStateRepository.updateState(applicationContext) {
            when (it.mode) {
                DeviceMode.TIMER -> it.copy(
                    timerRemainingSeconds = it.timerTotalSeconds,
                    isRunning = false,
                    isDone = false,
                    dialAngleDegrees = 0f
                )
                DeviceMode.STOPWATCH -> it.copy(
                    stopwatchElapsedMillis = 0L,
                    isRunning = false,
                    dialAngleDegrees = 0f
                )
            }
        }
        stopForeground(STOP_FOREGROUND_REMOVE)
    }

    private fun adjustTimerBySeconds(deltaSeconds: Int) {
        HardwareStateRepository.updateState(applicationContext) { cur ->
            val newTotal = (cur.timerTotalSeconds + deltaSeconds).coerceIn(15, 120 * 60)
            cur.copy(
                timerTotalSeconds = newTotal,
                timerRemainingSeconds = newTotal,
                isDone = false,
                dialAngleDegrees = 0f
            )
        }
    }

    /**
     * Synthesizes and plays a zero-asset hardware chime (880Hz / 1760Hz harmonious bell pulse)
     * and triggers a high-priority vibration alarm sequence when timer reaches 00:00.
     */
    private fun triggerCompletionAlarm() {
        // 1. Hardware vibration pulse sequence
        val vib = vibrator
        if (vib != null && vib.hasVibrator()) {
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
                val timings = longArrayOf(0, 250, 150, 250, 150, 400)
                val amplitudes = intArrayOf(0, 255, 0, 255, 0, 255)
                vib.vibrate(VibrationEffect.createWaveform(timings, amplitudes, -1))
            } else {
                @Suppress("DEPRECATION")
                vib.vibrate(longArrayOf(0, 250, 150, 250, 150, 400), -1)
            }
        }

        // 2. Synthesized audio chime via AudioTrack
        Thread {
            try {
                val sampleRate = 44100
                val durationMs = 600
                val numSamples = (sampleRate * (durationMs / 1000.0)).toInt()
                val pcm = ShortArray(numSamples)

                for (i in 0 until numSamples) {
                    val t = i.toDouble() / sampleRate
                    // Dual-frequency acoustic chime: 880Hz (A5) fundamental + 1760Hz octave overtone
                    val tone = 0.7 * sin(2.0 * PI * 880.0 * t) + 0.3 * sin(2.0 * PI * 1760.0 * t)
                    // Natural exponential acoustic decay
                    val envelope = kotlin.math.exp(-t * 6.5)
                    pcm[i] = ((tone * envelope) * 32767.0).toInt().coerceIn(-32768, 32767).toShort()
                }

                val track = AudioTrack.Builder()
                    .setAudioAttributes(
                        AudioAttributes.Builder()
                            .setUsage(AudioAttributes.USAGE_ALARM)
                            .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
                            .build()
                    )
                    .setAudioFormat(
                        AudioFormat.Builder()
                            .setEncoding(AudioFormat.ENCODING_PCM_16BIT)
                            .setSampleRate(sampleRate)
                            .setChannelMask(AudioFormat.CHANNEL_OUT_MONO)
                            .build()
                    )
                    .setBufferSizeInBytes(pcm.size * 2)
                    .setTransferMode(AudioTrack.MODE_STATIC)
                    .build()

                track.write(pcm, 0, pcm.size)
                track.play()
                Thread.sleep(700L)
                track.stop()
                track.release()
            } catch (e: Exception) {
                // Ignore audio chime recovery
            }
        }.start()
    }

    private fun createNotificationChannel() {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            val channel = NotificationChannel(
                CHANNEL_ID,
                "Neumorphic Hardware Timer",
                NotificationManager.IMPORTANCE_LOW
            ).apply {
                description = "Monotonic background precision countdown and stopwatch"
                setShowBadge(false)
            }
            val nm = getSystemService(NotificationManager::class.java)
            nm.createNotificationChannel(channel)
        }
    }

    private fun buildNotification(title: String, content: String): Notification {
        val launchIntent = packageManager.getLaunchIntentForPackage(packageName)
        val pendingIntent = PendingIntent.getActivity(
            this, 0, launchIntent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
        )

        // Action Intent: Toggle Start/Pause
        val toggleIntent = Intent(this, TimerForegroundService::class.java).apply {
            action = ACTION_TOGGLE
        }
        val togglePending = PendingIntent.getService(
            this, 1, toggleIntent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
        )

        // Action Intent: Reset
        val resetIntent = Intent(this, TimerForegroundService::class.java).apply {
            action = ACTION_RESET
        }
        val resetPending = PendingIntent.getService(
            this, 2, resetIntent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
        )

        val isRunning = HardwareStateRepository.state.value.isRunning
        val toggleLabel = if (isRunning) "Pause" else "Start"

        return NotificationCompat.Builder(this, CHANNEL_ID)
            .setContentTitle(title)
            .setContentText(content)
            .setSmallIcon(android.R.drawable.ic_lock_idle_alarm)
            .setOngoing(isRunning)
            .setContentIntent(pendingIntent)
            .addAction(android.R.drawable.ic_media_play, toggleLabel, togglePending)
            .addAction(android.R.drawable.ic_menu_revert, "Reset", resetPending)
            .setPriority(NotificationCompat.PRIORITY_LOW)
            .setVisibility(NotificationCompat.VISIBILITY_PUBLIC)
            .build()
    }

    private fun updateNotification(title: String, content: String) {
        val nm = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
        nm.notify(NOTIFICATION_ID, buildNotification(title, content))
    }

    override fun onDestroy() {
        super.onDestroy()
        handler.removeCallbacks(tickerRunnable)
    }

    override fun onBind(intent: Intent?): IBinder? = null
}

package com.neumorphic.hardwaretimer

import android.app.Application
import androidx.lifecycle.AndroidViewModel
import kotlinx.coroutines.flow.StateFlow

/**
 * ViewModel managing reactive UI state, user rotary adjustments, and delegating
 * background timing operations to the precision TimerForegroundService.
 */
class TimerStopwatchViewModel(application: Application) : AndroidViewModel(application) {

    val uiState: StateFlow<HardwareState> = HardwareStateRepository.state

    init {
        HardwareStateRepository.init(application.applicationContext)
    }

    /**
     * Toggles between running and paused states.
     */
    fun toggleRunning() {
        TimerForegroundService.startService(
            getApplication(),
            TimerForegroundService.ACTION_TOGGLE
        )
    }

    /**
     * Starts the active timer or stopwatch ticker.
     */
    fun start() {
        TimerForegroundService.startService(
            getApplication(),
            TimerForegroundService.ACTION_START
        )
    }

    /**
     * Pauses the active timer or stopwatch ticker.
     */
    fun pause() {
        TimerForegroundService.startService(
            getApplication(),
            TimerForegroundService.ACTION_PAUSE
        )
    }

    /**
     * Resets the active mode back to initial state (Timer resets to total duration; Stopwatch resets to 00:00).
     */
    fun reset() {
        TimerForegroundService.startService(
            getApplication(),
            TimerForegroundService.ACTION_RESET
        )
    }

    /**
     * Switches between Timer and Stopwatch modes, pausing any currently running operation.
     */
    fun setMode(newMode: DeviceMode) {
        val cur = uiState.value
        if (cur.mode != newMode) {
            pause()
            HardwareStateRepository.updateState(getApplication()) {
                it.copy(
                    mode = newMode,
                    isRunning = false,
                    isDone = false,
                    dialAngleDegrees = 0f
                )
            }
        }
    }

    /**
     * Handles rotary dial scrubbing.
     * Timer Mode:
     * - Under 5 minutes (< 300s): Quantized 15-second adjustments per 6-degree detent.
     * - 5 minutes and above (>= 300s): Quantized 1-minute (60s) adjustments per detent.
     * - Clamped within 15 seconds to 120 minutes.
     * Stopwatch Mode:
     * - Updates indicator sweep angle.
     */
    fun onDialAngleScrubbed(newAngle: Float, tickDiff: Int) {
        val cur = uiState.value
        val normalizedAngle = ((newAngle % 360f) + 360f) % 360f

        when (cur.mode) {
            DeviceMode.TIMER -> {
                if (!cur.isRunning) {
                    val stepSeconds = if (cur.timerTotalSeconds < 300) 15 else 60
                    val deltaSec = tickDiff * stepSeconds
                    val updatedTotal = (cur.timerTotalSeconds + deltaSec).coerceIn(15, 120 * 60)

                    HardwareStateRepository.updateState(getApplication()) {
                        it.copy(
                            timerTotalSeconds = updatedTotal,
                            timerRemainingSeconds = updatedTotal,
                            dialAngleDegrees = normalizedAngle,
                            isDone = false
                        )
                    }
                } else {
                    HardwareStateRepository.updateState(getApplication()) {
                        it.copy(dialAngleDegrees = normalizedAngle)
                    }
                }
            }
            DeviceMode.STOPWATCH -> {
                HardwareStateRepository.updateState(getApplication()) {
                    it.copy(dialAngleDegrees = normalizedAngle)
                }
            }
        }
    }
}

package com.neumorphic.hardwaretimer

import android.graphics.Bitmap

/**
 * 1:1 Bitmap renderer for Jetpack Glance AppWidget incorporating all key technical guardrails:
 * 1. Dedicated drawCircle shadow layer shifted y + 10.dp with BlurMaskFilter(24f, Blur.NORMAL).
 * 2. Inverted inner shadow stroke using LinearGradient from #B5B1A6 to #E8E4D9.
 */
object WidgetBitmapRenderer {

    const val BITMAP_SIZE = 600
    private const val BASE_SIZE = 320f
    private const val SCALE = BITMAP_SIZE / BASE_SIZE // 1.875f

    private fun dpToPx(dp: Float): Float = dp * SCALE

    fun renderWidgetBitmap(state: HardwareState): Bitmap {
        val bitmap = Bitmap.createBitmap(BITMAP_SIZE, BITMAP_SIZE, Bitmap.Config.ARGB_8888)
        val canvas = Canvas(bitmap)

        val size = BITMAP_SIZE.toFloat()
        val cx = size / 2f
        val cy = size / 2f
        val cornerRadius = dpToPx(48f)

        // 1. NEUMORPHIC CHASSIS BASE & SHADOWS
        drawChassis(canvas, size, cornerRadius)

        // 2. TOP INDICATORS ("Done" on left, "Start" on right)
        drawTopIndicators(canvas, size, state.isRunning, state.isDone)

        // 3. 12 RADIAL TICKS
        drawRadialTicks(canvas, cx, cy)

        // 4. RECESSED TRACK WELL WITH INVERTED INNER SHADOW STROKE (#B5B1A6 to #E8E4D9)
        drawRecessedWell(canvas, cx, cy)

        // 5. ROTARY PLATTER & DIAL POINTER
        drawRotaryPlatter(canvas, cx, cy, state.dialAngleDegrees)

        // 6. 3D CENTER KNOB WITH DEDICATED BLURMASKFILTER(24f) SHADOW
        drawCenterKnob(canvas, cx, cy, state.displayText)

        // 7. BOTTOM MODE PILLS
        drawBottomPills(canvas, size, state.mode)

        return bitmap
    }

    private fun drawChassis(canvas: Canvas, size: Float, cornerRadius: Float) {
        val shadowPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFFC4C0B5.toInt()
            maskFilter = BlurMaskFilter(dpToPx(12f), BlurMaskFilter.Blur.NORMAL)
        }
        val shadowRect = RectF(dpToPx(8f), dpToPx(10f), size + dpToPx(4f), size + dpToPx(6f))
        canvas.drawRoundRect(shadowRect, cornerRadius, cornerRadius, shadowPaint)

        val highlightPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFFEAE6DC.toInt()
            maskFilter = BlurMaskFilter(dpToPx(10f), BlurMaskFilter.Blur.NORMAL)
        }
        val highlightRect = RectF(-dpToPx(6f), -dpToPx(6f), size - dpToPx(6f), size - dpToPx(6f))
        canvas.drawRoundRect(highlightRect, cornerRadius, cornerRadius, highlightPaint)

        val bodyPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFFDDD9CE.toInt()
            style = Paint.Style.FILL
        }
        val chassisRect = RectF(0f, 0f, size, size)
        canvas.drawRoundRect(chassisRect, cornerRadius, cornerRadius, bodyPaint)

        val rimPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            shader = LinearGradient(
                0f, 0f, size, size,
                intArrayOf(0xFFEAE6DC.toInt(), 0x00000000, 0x40C4C0B5.toInt()),
                floatArrayOf(0f, 0.5f, 1f),
                Shader.TileMode.CLAMP
            )
            style = Paint.Style.STROKE
            strokeWidth = dpToPx(1.5f)
        }
        canvas.drawRoundRect(chassisRect, cornerRadius, cornerRadius, rimPaint)
    }

    private fun drawTopIndicators(canvas: Canvas, size: Float, isRunning: Boolean, isDone: Boolean) {
        val leftX = dpToPx(44f)
        val topY = dpToPx(40f)
        val rightX = size - dpToPx(44f)
        val ledRadius = dpToPx(6f)

        // --- TOP-LEFT: "Done" + Dark Well LED ---
        val wellPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFF2B261D.toInt()
            style = Paint.Style.FILL
        }
        canvas.drawCircle(leftX, topY, ledRadius, wellPaint)

        val dotPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = if (isDone) 0xFFFCE068.toInt() else 0xFF9E8C60.toInt()
            style = Paint.Style.FILL
        }
        canvas.drawCircle(leftX, topY, dpToPx(1.8f), dotPaint)

        if (isDone) {
            val doneGlowPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0x80FF9500.toInt()
                maskFilter = BlurMaskFilter(dpToPx(8f), BlurMaskFilter.Blur.NORMAL)
            }
            canvas.drawCircle(leftX, topY, dpToPx(10f), doneGlowPaint)
        }

        val textPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFF99958C.toInt()
            textSize = dpToPx(13f)
            typeface = Typeface.create(Typeface.SANS_SERIF, Typeface.NORMAL)
        }
        val doneFontMetrics = textPaint.fontMetrics
        val textY = topY - (doneFontMetrics.ascent + doneFontMetrics.descent) / 2f
        canvas.drawText("Done", leftX + dpToPx(12f), textY, textPaint)

        // --- TOP-RIGHT: "Start" + Amber LED ---
        val startTextWidth = textPaint.measureText("Start")
        canvas.drawText("Start", rightX - dpToPx(14f) - startTextWidth, textY, textPaint)

        if (isRunning) {
            val glowPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0x66FF9E1B.toInt()
                maskFilter = BlurMaskFilter(dpToPx(12f), BlurMaskFilter.Blur.NORMAL)
            }
            canvas.drawCircle(rightX, topY, dpToPx(12f), glowPaint)

            val borderPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0xFFD97200.toInt()
            }
            canvas.drawCircle(rightX, topY, ledRadius, borderPaint)

            val corePaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0xFFFF9E1B.toInt()
            }
            canvas.drawCircle(rightX, topY, dpToPx(4.5f), corePaint)

            val specPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0xFFFFF2D4.toInt()
            }
            canvas.drawCircle(rightX - dpToPx(1.2f), topY - dpToPx(1.2f), dpToPx(1.5f), specPaint)
        } else {
            val borderPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0x66D97200.toInt()
            }
            canvas.drawCircle(rightX, topY, ledRadius, borderPaint)

            val corePaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0x80FF9E1B.toInt()
            }
            canvas.drawCircle(rightX, topY, dpToPx(3.5f), corePaint)
        }
    }

    private fun drawRadialTicks(canvas: Canvas, cx: Float, cy: Float) {
        val innerR = dpToPx(122f)
        val outerR = dpToPx(128f)

        for (i in 0 until 12) {
            val angleDeg = i * 30f
            val angleRad = (angleDeg - 90f) * (PI / 180.0)

            val cosA = cos(angleRad).toFloat()
            val sinA = sin(angleRad).toFloat()

            val x1 = cx + innerR * cosA
            val y1 = cy + innerR * sinA
            val x2 = cx + outerR * cosA
            val y2 = cy + outerR * sinA

            val isCardinal12 = (i == 0)
            val tickPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = if (isCardinal12) 0xFFFF9500.toInt() else 0xFFBFB9AC.toInt()
                strokeWidth = if (isCardinal12) dpToPx(2.5f) else dpToPx(1.5f)
                strokeCap = Paint.Cap.ROUND
            }
            canvas.drawLine(x1, y1, x2, y2, tickPaint)
        }
    }

    /**
     * 4. Recessed Well:
     * GUARDRAIL FIX: Linear gradient from #B5B1A6 (top-left) to #E8E4D9 (bottom-right)
     * on the outer ring stroke creating the inverted inner shadow.
     */
    private fun drawRecessedWell(canvas: Canvas, cx: Float, cy: Float) {
        val r = dpToPx(112f)
        val wellPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFFCFCBC0.toInt()
            style = Paint.Style.FILL
        }
        canvas.drawCircle(cx, cy, r, wellPaint)

        // Diffuse top shadow
        val innerShadowPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            shader = LinearGradient(
                cx, cy - r, cx, cy + r,
                intArrayOf(0xFFA5A196.toInt(), 0xFFCFCBC0.toInt(), 0x66EAE6DC.toInt()),
                floatArrayOf(0f, 0.45f, 1f),
                Shader.TileMode.CLAMP
            )
        }
        canvas.drawCircle(cx, cy, r, innerShadowPaint)

        // Guardrail specification: Inverted inner shadow stroke
        val bevelStrokePaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            shader = LinearGradient(
                cx - r, cy - r, cx + r, cy + r,
                0xFFB5B1A6.toInt(), 0xFFE8E4D9.toInt(),
                Shader.TileMode.CLAMP
            )
            style = Paint.Style.STROKE
            strokeWidth = dpToPx(2f)
        }
        canvas.drawCircle(cx, cy, r, bevelStrokePaint)
    }

    private fun drawRotaryPlatter(canvas: Canvas, cx: Float, cy: Float, dialAngleDegrees: Float) {
        val r = dpToPx(104f)

        val dropPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0x33000000
            maskFilter = BlurMaskFilter(dpToPx(4f), BlurMaskFilter.Blur.NORMAL)
        }
        canvas.drawCircle(cx + dpToPx(2f), cy + dpToPx(3f), r, dropPaint)

        val platterPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            shader = LinearGradient(
                cx, cy - r, cx, cy + r,
                0xFFE4E0D5.toInt(), 0xFFD2CEC3.toInt(),
                Shader.TileMode.CLAMP
            )
        }
        canvas.drawCircle(cx, cy, r, platterPaint)

        val pInner = dpToPx(72f)
        val pOuter = dpToPx(98f)
        val rad = (dialAngleDegrees - 90f) * (PI / 180.0)

        val x1 = cx + pInner * cos(rad).toFloat()
        val y1 = cy + pInner * sin(rad).toFloat()
        val x2 = cx + pOuter * cos(rad).toFloat()
        val y2 = cy + pOuter * sin(rad).toFloat()

        val pointerGlow = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0x66FF9500.toInt()
            strokeWidth = dpToPx(5f)
            strokeCap = Paint.Cap.ROUND
        }
        canvas.drawLine(x1, y1, x2, y2, pointerGlow)

        val pointerPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFFFF9500.toInt()
            strokeWidth = dpToPx(3f)
            strokeCap = Paint.Cap.ROUND
        }
        canvas.drawLine(x1, y1, x2, y2, pointerPaint)
    }

    /**
     * 6. Center Knob:
     * GUARDRAIL FIX: Dedicated drawCircle shadow layer shifted y + 10.dp with BlurMaskFilter(24f, Blur.NORMAL).
     */
    private fun drawCenterKnob(canvas: Canvas, cx: Float, cy: Float, displayText: String) {
        val r = dpToPx(52f)
        val shadowOffset = dpToPx(10f)

        // Guardrail specification: Dedicated drawCircle shadow layer shifted y + 10.dp with BlurMaskFilter(24f, Blur.NORMAL)
        val shadowPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFF9E9A8F.toInt()
            maskFilter = BlurMaskFilter(24f, BlurMaskFilter.Blur.NORMAL)
        }
        canvas.drawCircle(cx, cy + shadowOffset, r, shadowPaint)

        // 3D side wall
        val sidePaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFFC2BEB3.toInt()
        }
        canvas.drawCircle(cx, cy + shadowOffset * 0.7f, r, sidePaint)

        // Top face
        val topPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            shader = LinearGradient(
                cx, cy - r, cx, cy + r,
                0xFFECE9DF.toInt(), 0xFFE2DFD5.toInt(),
                Shader.TileMode.CLAMP
            )
        }
        canvas.drawCircle(cx, cy, r, topPaint)

        // Typography
        val textPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
            color = 0xFF544D3C.toInt()
            textSize = if (displayText.length > 4) dpToPx(26f) else dpToPx(32f)
            typeface = Typeface.create(Typeface.SANS_SERIF, Typeface.BOLD)
            textAlign = Paint.Align.CENTER
        }
        val fm = textPaint.fontMetrics
        val textY = cy - (fm.ascent + fm.descent) / 2f
        canvas.drawText(displayText, cx, textY, textPaint)
    }

    private fun drawBottomPills(canvas: Canvas, size: Float, activeMode: DeviceMode) {
        val pillW = dpToPx(28f)
        val pillH = dpToPx(6f)
        val pillY = size - dpToPx(32f)
        val cr = dpToPx(4f)

        val leftX = dpToPx(48f) - (pillW / 2f)
        drawPill(canvas, leftX, pillY, pillW, pillH, cr, activeMode == DeviceMode.TIMER)

        val rightX = (size - dpToPx(48f)) - (pillW / 2f)
        drawPill(canvas, rightX, pillY, pillW, pillH, cr, activeMode == DeviceMode.STOPWATCH)
    }

    private fun drawPill(canvas: Canvas, x: Float, y: Float, w: Float, h: Float, cr: Float, isActive: Boolean) {
        val rect = RectF(x, y, x + w, y + h)
        if (isActive) {
            val fillPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0xFFF5B800.toInt()
            }
            canvas.drawRoundRect(rect, cr, cr, fillPaint)

            val bevelPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                shader = LinearGradient(
                    x, y, x, y + h,
                    0xFFC99300.toInt(), 0x00000000,
                    Shader.TileMode.CLAMP
                )
            }
            canvas.drawRoundRect(rect, cr, cr, bevelPaint)

            val rimPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                shader = LinearGradient(
                    x, y, x, y + h,
                    0x00000000, 0xFFFCE068.toInt(),
                    Shader.TileMode.CLAMP
                )
                style = Paint.Style.STROKE
                strokeWidth = dpToPx(1f)
            }
            canvas.drawRoundRect(rect, cr, cr, rimPaint)
        } else {
            val dimPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
                color = 0xFFC4C0B5.toInt()
            }
            canvas.drawRoundRect(rect, cr, cr, dimPaint)
        }
    }
}

/**

 * Bridges Jetpack Glance with the full Jetpack Compose Canvas touch pipeline,
 * allowing users to smoothly spin the dial at 60fps with real-time synthesized audio clicks
 * and hardware haptics without RemoteViews gesture limitations.
 */
class QuickDialOverlayActivity : ComponentActivity() {

    private val viewModel: TimerStopwatchViewModel by viewModels()
    private lateinit var tactileEngine: TactileFeedbackEngine

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        tactileEngine = TactileFeedbackEngine(this)

        setContent {
            val uiState by viewModel.uiState.collectAsState()

            // Translucent dim backdrop - tapping outside dismisses the overlay
            Box(
                modifier = Modifier
                    .fillMaxSize()
                    .background(Color.Black.copy(alpha = 0.55f))
                    .clickable(
                        interactionSource = remember { MutableInteractionSource() },
                        indication = null
                    ) {
                        finish()
                    },
                contentAlignment = Alignment.Center
            ) {
                // Fully interactive hardware dial composable
                NeumorphicDialCanvas(
                    mode = uiState.mode,
                    displayText = uiState.displayText,
                    dialAngleDegrees = uiState.dialAngleDegrees,
                    isRunning = uiState.isRunning,
                    isDone = uiState.isDone,
                    tactileEngine = tactileEngine,

                        viewModel.onDialAngleScrubbed(newAngle, tickDiff)
                    },
                    onKnobTapped = {
                        viewModel.toggleRunning()
                    },
                    onKnobLongPressed = {
                        viewModel.reset()
                    },
                    onStartAreaTapped = {
                        viewModel.toggleRunning()
                    },
                    onModeChanged = { newMode ->
                        viewModel.setMode(newMode)
                    }
                )
            }
        }
    }

    override fun onDestroy() {
        super.onDestroy()
        tactileEngine.release()
