# Neumorphic Hardware Timer & Stopwatch (Android + Jetpack Glance)

[![Build Android APKs & Release](https://github.com/harrisz123/neumorphic-hardware-timer/actions/workflows/build-apk.yml/badge.svg)](https://github.com/harrisz123/neumorphic-hardware-timer/actions/workflows/build-apk.yml)

An ultra-realistic, 1:1 hardware clone of an industrial precision rotary timer and stopwatch built with **Kotlin**, **Jetpack Compose Canvas**, and **Jetpack Glance 1.1.0** Home Screen Widgets.

---

## Hardware Aesthetic & Visual Specifications
- **Chassis Body:** Warm matte stone/beige (`#DDD9CE`) with soft ambient drop shadows (`#C4C0B5`) and top-left specular highlight (`#EAE6DC`).
- **Recessed Track Well:** Dual-tone carved annular trench (`#CFCBC0`) with inverted inner shadow stroke (`#B5B1A6` to `#E8E4D9`).
- **Main Rotary Platter:** Brushed stone gradient (`#E4E0D5` to `#D2CEC3`) with an illuminated orange pointer (`#FF9500`).
- **Center 3D Knob Cap:** Floating extruded cylinder (`#E2DFD5` top face, `#C2BEB3` 3D side wall) elevated with a dedicated 10dp drop shadow via `BlurMaskFilter(24f, Blur.NORMAL)`.
- **Top Indicators:**
  - Left: Sunken well (`#2B261D`) with specular apex dot (`#9E8C60`) and "Done" indicator.
  - Right: Glowing amber core (`#FF9E1B`), inner border (`#D97200`), and outer radial halo (`0x66FF9E1B`) with "Start" indicator.
- **Bottom Mode Pills:** Recessed bevel pills for Timer and Stopwatch modes (`#F5B800` active fill, `#C4C0B5` inactive).

## Audio & Haptics Engine (`TactileFeedbackEngine`)
- **Zero-Asset In-Memory PCM Audio:** Synthesizes an exponentially decaying burst of resonant bandpass-filtered noise (2800Hz, Q=2.4) + an 1800Hz metallic sine transient into a 176-sample ShortArray (4ms at 44.1kHz). Played via low-latency static `AudioTrack` with near-zero latency.
- **Continuous Rotary Math:** Polar angle tracking via `atan2` with continuous wrap-around normalization (`if (delta > 180) delta -= 360; if (delta < -180) delta += 360`) and discrete 6° detent quantization.
- **Hardware Haptics:** Direct API 30+ `VibrationEffect.Composition` primitive clicks with fallbacks.
- **Synthesized Completion Chime:** Dual-tone harmonious bell chime (880Hz A5 + 1760Hz overtone) on timer finish.

---

## Home Screen Widget & Fast-Scrub Overlay
- **Dual-Mode Widget (`Jetpack Glance 1.1.0`):** Renders to a 600x600 offscreen `Bitmap` canvas to circumvent `RemoteViews` gesture conflicts.
- **Interactive Tap Zones:** Overlaid transparent Glance targets for direct Start/Pause toggling and ±1m quick steps.
- **Instant 60fps Scrub Overlay (`QuickDialOverlayActivity`):** Launches a translucent floating dial over the widget so users can smoothly scrub the dial with real-time sound and haptic detents.
